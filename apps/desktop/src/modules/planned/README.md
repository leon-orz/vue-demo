# 规划中模块占位

> 五个规划中模块（信息订阅、AI 网关、系统优化、网络优化、开发环境）共用的占位页。边界与目标见 [产品说明](../../../../../docs/01-产品说明.md)。

## 功能

为已登记导航但未实现的模块提供统一占位：显示"规划中"徽标、`app/modules.ts` 中该模块 `planned` 字段的目标描述，以及跳转文档指引。**不发起任何业务 IPC、不持久化任何状态**——这是占位页唯一的硬约束。

## 逻辑链路

```text
app/modules.ts（planned 字段 = 目标描述 + 规划中标记）
  → app/router.ts（业务路由统一注入）
  → PlannedPlaceholder.vue（读 route.path 匹配模块，渲染描述）
```

## 转正流程

模块正式实现时：

1. 在 `modules/<id>/` 新建真实页面，`app/modules.ts` 替换 `route.component`、删除 `planned` 字段、按需补 `dashboard` 卡。
2. 删除本目录占位（最后一个模块转正后整个 `planned/` 可移除）。
3. 按 [模块开发指南](../../../../../docs/04-模块开发指南.md) 补 IPC、类型、测试与文档。
