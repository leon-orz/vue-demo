# Toogl 产品说明

> Toogl（图格）是面向 Windows 10/11 的个人桌面实用工具箱。本文描述产品定位、各模块的用户能力和安全边界；实现事实与架构见 [架构与数据流](02-架构与数据流.md)，当前进度与下一步方向见 [开发状态与方向](03-开发状态与方向.md)。

## 产品定位

Toogl 围绕个人 Windows 使用中的高频任务组织功能：使用 mihomo 代理、消费信息订阅、管理 AI 模型网关用量、优化系统与网络、维护开发环境，以及管理应用自身偏好。

产品原则：

- 魔法工具（mihomo 代理）是当前唯一完整实现的模块，其余模块按规划逐步落地。
- 首页看板汇总各模块状态并提供入口，不复制模块业务逻辑。
- 其他模块保持边界小、行为可解释。
- Windows 10/11 是唯一桌面平台，不扩展 macOS/Linux。
- 破坏性动作（改系统设置、结束进程、删除文件）必须先展示范围并获得用户逐次确认，不以"优化"为名静默执行。

当前不承诺：TUN、远程 Hub、手机端、多用户、自动化无确认的系统修改。

## 模块边界

### 魔法工具（已实现）

#### 最小闭环

```text
启动 mihomo → 查看状态 → 选择节点 → 切换模式 → 开启系统代理 → 正常退出并恢复
```

#### 总览

- mihomo 运行状态、版本提示（期望 v1.19.32）和启动失败原因。
- 系统代理开关及注册表实际状态。
- 规则、全局、直连三个模式。
- 当前代理组和节点。
- 异常退出后的系统代理残留提示和确认恢复入口。

只做 Windows 系统代理；不做 TUN、虚拟网卡、进程级代理或 PAC。

#### 节点

- mihomo `/proxies` 是代理组和当前节点事实源。
- `selector` 组支持手动切换；其他组类型只读展示。
- 批量测速为用户主动操作，并发上限 16；单节点失败不拖垮其他节点。
- 页面可见时约 4 秒轮询，隐藏窗口跳过，离开停止；切换失败回滚界面状态。

#### 节点来源

订阅：

- 仅接受 HTTP/HTTPS URL，拉取固定超时并使用 Clash 客户端 UA。
- 支持 Clash/mihomo YAML、Base64 分享链接列表和纯文本分享链接。
- 分享链接支持 `vless`、`ss`、`trojan`、`hysteria2`/`hy2`；不支持 `vmess`。
- 只提取节点，不覆盖本机整套规则、端口和其他配置。
- 支持保存链接、立即更新、后台 24 小时更新。

手动导入：

- 多行文本逐条解析，坏行返回失败明细，有效节点继续导入。
- 同名手动节点覆盖旧手动节点；与订阅节点合并时手动优先。

统一更新链路与失败回滚见 [架构与数据流](02-架构与数据流.md#订阅链路)。

#### 安全与生命周期

- mihomo controller 和代理入口默认只监听回环地址；controller 使用随机 secret。
- 应用退出先恢复系统代理，再回收 mihomo 子进程。
- sidecar 启动失败只让魔法工具降级，不阻塞其他模块和看板。
- 不向前端开放任意配置键、任意命令或任意文件路径。

### 信息订阅（未实现）

规划目标：聚合用户关心的 RSS 源与 GitHub 信息（如 Release、Watch 仓库动态），统一查看。

- 具体信息结构、刷新策略和界面形态待定，待需求确定后补充本节并更新模块开发指南。
- 安全边界沿用全仓约束：固定或用户显式配置的源地址，不执行源内容中的任何脚本。

### AI 网关（未实现）

规划目标：查看自建 AI 模型聚合中转平台的模型清单、用量统计和健康状态。

- 依赖用户搭建好平台后提供对接 API；接口确定前不预设数据模型，不写占位实现。
- API 密钥属于用户凭据：存放在本机数据库，不进入日志、前端展示默认脱敏。

### 系统优化（未实现）

规划目标：游戏相关设置检查与后台占用清理。

- 硬边界：任何修改系统设置、结束进程、删除文件的动作，必须先展示受影响对象清单并获得用户逐次确认；只读检查可自动进行。
- 游戏设置涉及注册表和电源计划，只处理白名单内的已知键值；后台清理先列后清，不支持通配删除。

### 网络优化（未实现）

规划目标：网络状态检测与修复。

- 修复动作（刷新 DNS、重置适配器等）逐项确认后执行；检测目标固定或由用户显式配置。
- 不做流量抓包、不做代理链路改写（代理能力归属魔法工具）。

### 开发环境（未实现）

规划目标：端口冲突检测、残留进程定位与处理等开发环境辅助。

- 结束进程是破坏性动作：先展示进程名、PID 与监听端口，用户确认后逐个执行；不批量杀进程。
- 只使用系统自带工具（如 `netstat`、`tasklist`、`taskkill`）的固定参数，不接受前端传入任意命令或路径。

### 软件设置（已实现）

只管理主题（亮色 / 暗色 / 跟随系统）和版本信息。不显示未实现的开机自启、窗口行为、置顶、TUN 等开关。

## 数据归属

| 数据 | 事实源或存储位置 |
| --- | --- |
| mihomo 存活、当前节点和代理组 | mihomo REST API |
| 规则模式 | mihomo `/configs`；本地记忆值只作降级展示 |
| 系统代理真实状态 | Windows 注册表 |
| 原系统代理备份 | `toogl.db` 的 `proxy_setting` KV |
| 订阅 URL、节点元信息、手动节点 | `toogl.db` 的 `proxy_setting` KV |
| 托管节点 | mihomo 工作目录中的 `toogl-nodes.yaml` |
| 主题偏好 | `toogl.db` 的 `preference` 表；localStorage 仅作首屏缓存 |
| 订阅源、AI 网关凭据、优化/环境处理记录 | 未实现；落地时各自登记事实源 |
| 其余模块会话内结果 | 各模块内存状态，不持久化 |

Rust `models/` 是跨语言契约唯一来源，TypeScript bindings 自动生成，禁止手改。
